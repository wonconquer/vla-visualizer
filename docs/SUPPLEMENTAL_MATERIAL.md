# Supplemental material

This repository provides executable source, tests, pinned dependency manifests,
two sample camera images, their measured state/instruction, one small recorded
episode table, and real inference/training captures. The README describes how
to open the saved capture without downloading model weights and how to run a
new pretrained inference.

The supplied midproject `.tex` file is a VGTC/TVCG manuscript template. Its
supplemental-material instructions encourage a publicly accessible repository
and a description of available materials, hosting, and omissions. Its figure
guidance requests source credits and alternative text. It does not contain a
course-specific rubric, deadline, or AI-use policy; none is inferred here.

This repository supplies the code supplement. It is not a completed manuscript
and does not claim user-study results, robotics task success, or a live public demo.
The template's example authors, title, figures, filler text, and example funding
statement are not project content and are not copied into the submission.

Excluded material:

- Model weights and the full dataset: prepared separately from immutable pins.
- Virtual environments, caches, generated jobs, session receipts, and credentials.
- Internal handoff prompts, machine-specific logs, and duplicate development reports.
- Simulator rollout videos and browser screenshots: these were not validated and
  are not represented by placeholders.

The project uses the upstream pretrained policy and dataset identified in
[data provenance](DATA.md). The source model, data, and dependency credits are
listed in [THIRD_PARTY.md](../THIRD_PARTY.md).
